# Surface landing page — hoạt động 449

Mở `index.html` bằng Live Server hoặc trình duyệt. Giao diện Bootstrap gồm navbar collapse, hero, lưới thẻ sản phẩm, khối nội dung, FAQ accordion và modal so sánh. Hầu hết bố cục và khoảng cách dùng utilities Bootstrap; CSS riêng chỉ phục vụ nhận diện, ảnh và một số chi tiết.

Mẫu đề bài `https://www.microsoft.com/en-us/store/b/surface` hiện chuyển tới https://www.microsoft.com/en-us/surface . Đã đọc trang này ngày 19/10/2026 để tham khảo các vùng hero, thiết bị và FAQ. Không sao chép HTML của trang. Không đưa giá, pin hay cấu hình chưa kiểm chứng vào bài.

Ảnh dùng trực tiếp từ trang Microsoft, bản quyền Microsoft, chỉ phục vụ bài tập thiết kế. Bốn đường dẫn nguồn nằm trong `index.html`: COM_100_Hero_Mobile_Poster.jpg, COM_Pro.jpg, COM_Laptop.jpg, COM_Rayne.jpg từ CDN images.ctfassets.net được trang chính thức liên kết.
